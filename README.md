# AICTE Health Assistant

**Developed by: ARYANRAJ MALEPU**

## 🩺 Project Overview

**AICTE Health Assistant** is a Python-based AI health monitoring and assistance program designed to help users track and reflect on their **day-to-day health habits and general wellness-related information**.

The project uses **Natural Language Processing (NLP)** techniques to process user-provided information and determine a general health-related condition or response based on the input.

The system demonstrates how Python and basic AI/NLP concepts can be applied to create an interactive health-assistance application.

> **Disclaimer:** This project is intended for educational and informational purposes only. It is not a medical diagnostic system and should not be used as a replacement for professional medical advice.

## 🎯 Project Objective

The main objective of the AICTE Health Assistant is to demonstrate the use of **Artificial Intelligence, Natural Language Processing, and Python programming** to create a simple system that can interact with users regarding their everyday health habits.

The project focuses on converting user-provided information into meaningful, understandable responses.

## 🧠 How It Works

The basic workflow of the application can be represented as:

```text
User Input
    ↓
Text Processing
    ↓
NLP Analysis
    ↓
Health-Related Assessment
    ↓
Response / Result
```

The user provides information related to their everyday health habits. The program processes the input using NLP-based techniques and produces a general response based on the information provided.

## 🚀 How to Run

### 1. Install Python

Check whether Python is installed:

```bash id="healthpython"
python3 --version
```

If Python is not installed on Ubuntu/Debian Linux:

```bash id="healthinstall"
sudo apt update
sudo apt install python3
```

### 2. Download or Clone the Project

If the project is available as part of the repository:

```bash id="healthclone"
git clone https://github.com/ayvan6/ayvan6.git
```

Enter the project directory or navigate to the location containing the health assistant program.

### 3. Run the Program

If the main program is a Python file, run it using:

```bash id="healthrun"
python3 <filename>.py
```

Replace `<filename>.py` with the actual Python filename of the Health Assistant program.

## 💻 Windows

On Windows, verify Python installation:

```cmd id="healthwindows"
python --version
```

Then run:

```cmd id="healthwindowsrun"
python <filename>.py
```
